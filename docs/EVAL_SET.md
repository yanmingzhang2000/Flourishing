# 评测集样例（离线 Eval Set）

> 关联文档：PRODUCT_LOGIC_v2.1_修订版.md（§十六）
> 范围：四类离线评测（决议 16）——禁忌拦截 / 时长计算 / 恢复排期 / 组合分配
> 用法：作为回归基线，任何计划生成逻辑改动后跑全量；新增 badcase 追加进回归集。

---

## 评测分层与目标

| 层 | 指标 | 通过阈值（建议，§12.3 遗留项 5） |
|----|------|-------------------------------|
| 规则层 | 禁忌排除准确率 | **100%** |
| 规则层 | 时长计算正确率 | ≥ 99% |
| 规则层 | 48h 恢复合规率 | 100% |
| RAG 层 | 禁忌检索命中率 | ≥ 98% |
| 业务层 | 计划采纳率 | > 50% |
| 业务层 | 训练完成率 / 留存 | 看基线，迭代提升 |

## 一、禁忌拦截（规则 + RAG，准确率 100%）

**Case T-01：肩伤排除肩相关动作**
- 输入：`injuries = ["shoulder"]`，项目 = 拜拜肉收紧 + 圆肩改善
- 映射展开：`shoulder` → `shoulder_impingement`, `rotator_cuff`
- 期望：动作库中所有 `contraindications` 含上述标签的动作被**确定性排除**
- 断言：`dumbbell_lateral_raise`（含 `shoulder_impingement`）不得出现在计划中
- 放行：`plank`（无肩标签）可保留

**Case T-02：颈伤排除颈相关动作**
- 输入：`injuries = ["neck"]`
- 映射展开：`neck` → `neck_pain`
- 期望：含 `neck_pain` 的动作排除（依赖用户选项已补"颈"，§二）
- 断言：含 `neck_pain` 标签动作 0 出现

**Case T-03：多伤病叠加**
- 输入：`injuries = ["shoulder", "knee"]`
- 期望：肩标签 ∪ 膝标签（`knee_pain`, `meniscus`）命中动作全排除
- 断言：排除集合 = 两标签命中并集，不遗漏

**Case T-04：无伤病不误杀**
- 输入：`injuries = []`
- 期望：不因空伤病而误排除任何动作
- 断言：计划动作数 = 正常筛选结果

---

## 二、时长计算（规则，正确率 ≥99%）

公式：`总时长 = Σ(各项目主训练时长) + 固定热身 5min`（§2.3 / §6.1）

| Case | 输入项目 | 期望总时长 |
|------|---------|-----------|
| D-01 | 拜拜肉(15) | 15 + 5 = 20min |
| D-02 | 拜拜肉(15) + 下腹(15) | 30 + 5 = 35min |
| D-03 | 假胯宽(20) + 下腹(15) + 圆肩(15) | 50 + 5 = 55min |
| D-04 | 居家基础体能(25) + 斜方肌放松(10) | 35 + 5 = 40min |

- 断言：实际输出 ∈ [期望-0, 期望+5]（允许 ±5 微调）
- **回归点**：原 v2.0 公式 `基础×项目数×1.2` 对 D-02 会算出 60-84min，已修复，此 case 防回归。

## 三、恢复排期（规则，48h 合规率 100%）

**Case R-01：单项目 5 天意愿 → 隔天排期**
- 输入：项目 = 拜拜肉，训练天数意愿 = 5
- 期望：实际训练日排为隔天（如 周一/三/五/六），任一肌群间隔 ≥ 48h
- 断言：相邻训练日间隔 ≥ 1 天；同肌群（肱三头肌）两次训练间隔 ≥ 48h

**Case R-02：7 天全选 → 强制插入恢复**
- 输入：训练天数意愿 = 7
- 期望：系统不安排同动作连练；插入主动恢复 / 变式日
- 断言：无连续两天训练同一肌群；每周至少 1-2 天恢复

**Case R-03：多项目交替满足恢复**
- 输入：拜拜肉 + 下腹，训练日 周一/三/五/六
- 期望：每天组合训练，但拜拜肉（臂）与下腹（腹）各自满足 48h
- 断言：臂肌群训练日间隔 ≥ 48h 且腹肌群同理

---

## 四、组合分配（规则 + AI 优化，比例合理）

**Case C-01：全身 + 局部去重**
- 输入：居家基础体能(全身) + 拜拜肉(手臂)
- 期望：重叠肌群（手臂/腹）单次覆盖提示，不重复高量
- 断言：手臂类动作总数不超过单项目上限的 1.5 倍；有去重提示字段

**Case C-02：每天组合训练默认**
- 输入：拜拜肉 + 下腹，训练日 周一/三/五/六
- 期望：每个训练日同时含两项目动作（方案 A 默认）
- 断言：每日计划同时出现 `target_projects` 含两项目的动作

**Case C-03：器械过滤生效**
- 输入：equipment = 仅 `bodyweight`（无器械）
- 期望：所有需哑铃/弹力带等动作被过滤
- 断言：计划动作 `equipment` 均 ⊆ 用户 equipment

## 五、Badcase / 回归集（示例格式）

```json
  "regression": true
```

```json
  "fix": "改为 Σ主训练 + 固定 5min",
  "assert": "输出 35min",
  "regression": true
}
```

## 六、评测执行建议

1. 离线集随动作库扩张同步扩充（每条新动作至少贡献 1 个禁忌/组合 case）。
2. CI 中运行规则层 + RAG 层断言，不通过禁止发布。
3. 业务层指标（采纳率/完成率/留存）上线后持续监控，按周复盘。
4. 重要 badcase 修复后必须进 §五 回归集，防止"修一个坏一个"。
